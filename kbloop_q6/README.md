# 地址几何与知识复利的小实验（问题 6）

问题：知识地址的几何，能否决定知识复利？之前的实验只测了遗忘，圆盘改动之间也没有可复用的结构，所以看不到复利。这是一个玩具实验，看第 3、4 个改动是否比第 1 个便宜。代码在 `science-of-ai-prototype-cppn` 的 `research/cppn_address_probe*`，用这个家族的网络和判定代码，但不走 `kb_lab.run_job`。

**结论：没有验证成功。** 第二版看到了一个支持几何重要的方向，但样本太少，而且有一个混淆因素。

## 第一版（`7940cca`）：没有检验到任何东西

4 组共 192 次改动全部在 100 步内没学会，比值 1.0 是上限造成的，所以 K9502、K9503 判为成立没有意义（`v1/`）。原因是我把图样定得太难，网络又缩得太小。

之后在实验之外的目标（中心一个实心圆）上校准（`calibrate.py`）。坐标地址 25 步内误差就到约 0.03。完全打乱像素的坐标后，200 步内误差一直停在约 0.2，接近猜测水平。所以完全打乱时比较不出复利，只能说这个规模的网络学不动。

## 不能这样读

- **不是几何决定复利的证据。** 共享图样下 0.87 对 1.65 的差距方向对，但只有 3 个网络，其中一个反过来，而且原始坐标组本身也没到 0.7。
- **比值下降不等于复利。** 图块打乱加不相关图样没有可复用的结构，比值却是 0.57，成本从 34.5 降到 13。这说明后面的改动变便宜可能有别的原因，比如优化器状态或网络状态的变化，这里没有区分。这是最大的混淆，下一版必须有对照。
- **分辨率不够。** 共享图样只要 4～6 步，整数步数太粗。
- **比值的基线不独立。** 第二版的设置是看到第一版失败后才改的，校准只用了实验之外的目标，但也不算盲测。
