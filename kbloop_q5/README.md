# 旋钮改动（问题 5）

之前的连续改动都是局部颜色反转，这类改动可能本来就不利于 Picbreeder。这轮测论文指向的改动：把一个现存权重改变 1，只引起局部可见的变化，比如 skull 张嘴。代码是 `science-of-ai-prototype-cppn` 的 `efe8e1c`，预测 K9401～K9408 在同一提交的 `research/cppn_knob_seq_20261101/seed_kb.json`，运行前已推送，之前只跑过 5 步的冒烟测试。选择规则定在运行前，当时只看过改动本身。在 RTX 4060 上运行，27 个实验全部成功，没有调用 LLM。

互不重叠的 4 个旋钮在 skull、butterfly 上不存在，所以每次学一对，两种顺序都跑，每张图 6 对。目标是源网络自己画出来的，所以对 Picbreeder 来说只需移动那两个权重就能精确达到，这个设定偏向它。

## 结果

都是无回放时与稠密网络（G0）的比值，依次是 skull、butterfly、apple。

| Claim | 比较 | 比值 | 判定 |
|---|---|---|---|
| K9401 | PBd 改动后的误差（≤ 0.5） | 19.3、10.4、13.3 | 证伪 |
| K9402 | PBa 改动后的误差（≤ 0.5） | 18.9、13.5、24.7 | 证伪 |
| K9403 | PBd 第一次改动的区外变动（≤ 0.5） | 1.84、1.15、2.91 | 证伪 |
| K9404 | PBa 第一次改动的区外变动（≤ 0.5） | 1.01、0.25、0.36 | 证伪（skull 不过线，其余两张图过线） |
| K9405 | PBd 学第二个旋钮时的遗忘量（≤ 0.5） | 1.05、0.78、1.61 | 证伪 |
| K9406 | PBa 的遗忘量（≤ 0.5） | 0.93、0.63、1.24 | 证伪 |
| K9407 | 对照：稠密网络的旋钮上，PBd 的误差（≥ 1） | 37.0、8.8、8.7 | 成立 |
| K9408 | 稠密网络学会了这些改动（中位数 ≤ 0.3） | 0.007、0.014、0.002 | 成立 |

- 用梯度学习时，Picbreeder 在自己的旋钮上也没有学得更好，也没有忘得更少。
- 对照说明，误差差距和旋钮来自谁关系不大：在自己的旋钮上是 10～19 倍，在稠密网络的旋钮上是 9～37 倍。
- 例外是 PBa 在 butterfly 和 apple 上的区外变动很小（0.25、0.36）。但它改动后的误差也是稠密网络的 13～25 倍，所以可能只是动得少，这一点没有区分。

## 不能得出的结论

这轮测的是**梯度下降**能否用上旋钮，不是旋钮是否存在。旋钮确实存在，而且看起来有语义：Picbreeder 的改动保持对称和结构，稠密网络的常出现不对称的斑块（`knob_examples.png`，事后的肉眼观察，没有量化）。论文的表示差异可能只对变异或搜索有用，这里没有测。

其他限制：

- 每张图只有一个 Picbreeder 网络，同一网络的多个改动不是独立样本，逐行的波动也很大（比如 skull 上 PBa 的遗忘量从 0.11 到 3.3）。
- apple 的学习率是 3e-4，500 步内 Adam 最多把一个权重移动约 0.15，所以到不了移动 1 的那个精确解。skull 和 butterfly 最多约 1.5，够得到但余量不大。
- 旋钮的选择规则（改变量 1、面积不超过 30% 等）是我定的，换规则结果可能不同。
- 学习率沿用训练时的值，没有针对 Picbreeder 调整。

## 事后观察：局部单权重改动的数量

这是运行前检查规则时看到的，只算描述。按同一规则，随机取样的边中符合条件的比例：skull 上 Picbreeder 约 39%，稠密约 58%；butterfly 上约 34% 对约 70%；apple 上约 55% 对约 21%（改变量 ±1 和 ±0.5 的大致范围）。可用的互不重叠旋钮数，Picbreeder 在 skull、butterfly 上也更少。
