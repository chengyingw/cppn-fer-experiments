# Picbreeder 的连续改动测试（问题 3）

问题 1、2 的连续改动只跑了稠密网络，所以 Picbreeder 是否更不容易遗忘一直没有数据。这轮补上。代码是 `science-of-ai-prototype-cppn` 的 `c20aa25`，预测 K9201～K9208 在同一提交的 `research/cppn_picbreeder_seq_20261101/seed_kb.json`，运行前已推送。在 RTX 4060 上运行，走 `kb_lab.run_job`，没有调用 LLM。

每张图 3 组起点（PBd 全部权重可学，PBa 只训练现存边，G0 稠密），每组无回放、均匀 5%、聚焦 5%，各有原始输出和保留梯度两种，共 54 个实验，全部成功。稠密组原始输出的结果和 `kbloop_q1/local/` 一致到 4 位小数（`replay0`、`replay0.05`）。

## 结果

| Claim | 判定 | 比值或中位数（skull、butterfly、apple） |
|---|---|---|
| K9201 无回放时 PBd 的遗忘量不超过 G0 的一半（保留梯度） | 证伪 | 0.91、1.01、1.69 |
| K9202 同上，按相对遗忘量 | 证伪 | 0.91、1.02、1.64 |
| K9203 PBd 学会了改动（R_after ≤ 0.1） | 成立 | 0.011、0.025、0.043 |
| K9204 PBa 的遗忘量不超过 G0 的一半 | 证伪 | 1.86、0.56、5.52 |
| K9205 PBa 学会了改动 | 成立 | 0.017、0.075、0.007 |
| K9206 PBd 的背景漂移至少是 G0 的 2 倍 | 证伪 | 1.00、0.86、1.07 |
| K9207 聚焦回放对 PBd 也有效（≤ 0.6） | 成立 | 0.20、0.29、0.14 |
| K9208 原始输出下 PBd 的遗忘量不超过 G0 的一半 | 证伪 | 1.28、1.34（只测两张图） |

- 这 3 个网络在这类改动上，Picbreeder 没有遗忘得更少。
- 只有 PBa 在 butterfly 上低于 G0，但没有到一半，而且改动留下的误差是 G0 的约 6 倍（0.075 对 0.012）。
- K9206 是我根据 C-022 写的预测，错了。单次改动时 Picbreeder 区外变动更大，但连续改动且无回放时，背景漂移和稠密网络差不多。原因没有查。
- 聚焦回放在这台机器上也复现了：稠密组原始输出的比值是 0.23（skull）和 0.28（butterfly），问题 2 在 A100 上是 0.19 和 0.24。这是同一配置换机器重跑，不是新的预测。

## 预测里写错的一点

K9201 到 K9207 的范围说明写了“保留梯度后 apple 没有陷阱”，这不对。在 apple 的连续改动中：

| 条件（稠密组） | 改动结束时在灰色残差附近的比例 | R_after 中位数 |
|---|---|---|
| 无回放，原始 | 35% | 0.001 |
| 无回放，保留梯度 | 21% | 0.080 |
| 均匀 5%，原始 | 46% | 0.002 |
| 均匀 5%，保留梯度 | 6% | 0.082 |

保留梯度让卡在灰色的比例下降，但误差中位数升高。所以它只在单个改动加 100% 回放时算修复（0.135 降到 0.004），不是通用的办法。这也让 apple 上保留梯度的比较不够干净，结论主要依靠 skull、butterfly 和原始输出的结果。

## 局限

每张图只有一个 Picbreeder 网络，它的 12 行遗忘量不是独立样本，两组分布也有很大重叠。改动都是局部颜色反转，这类改动可能本来就不利于 Picbreeder，论文里的“旋钮”改动没有测。学习率也沿用训练时的值，没有针对 Picbreeder 调整。
